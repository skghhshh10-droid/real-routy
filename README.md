# Routy — 개인용 AI 여행 플래너

Google Gemini로 **실제 장소** 기반 여행 일정을 만들고, 지도·타임라인으로 다듬어 쓰는 웹앱입니다.
서버 없이 정적 파일만으로 동작하며, 데이터는 모두 내 브라우저(localStorage)에 저장됩니다.

## 시작하기

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 Gemini API 키 발급 (무료 등급으로 개인 사용 충분)
2. 앱 실행 → **설정** 탭 → API 키 붙여넣기 → **연결 테스트**
3. **AI 플래너** 탭에서 목적지·출발일·동행·스타일·요청사항 입력 → 생성

키가 없으면 기존 샘플(목업) 일정이 만들어집니다.

## 실행 / 배포

- 로컬: `python3 -m http.server 8000` 후 `http://localhost:8000`
- 휴대폰에서 쓰기: GitHub 저장소 **Settings → Pages → Deploy from branch (main / root)** 로 켜면
  `https://<아이디>.github.io/real-routy/` 에서 열립니다. 브라우저 메뉴의 **홈 화면에 추가**로 앱처럼 설치되고,
  한 번 연 일정은 오프라인에서도 볼 수 있습니다 (service worker).

> API 키는 브라우저에만 저장되지만, 공개 페이지라도 키는 각자 입력하는 구조라 저장소에 키가 올라가지 않습니다.
> 그래도 AI Studio에서 키에 **HTTP 리퍼러 제한**(내 github.io 주소)을 걸어두면 더 안전합니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| AI 일정 생성 | 목적지, 출발일(계절/요일 반영), 기간(최대 10일), 동행, 예산, 다중 스타일, 자유 요청사항 |
| AI 수정 요청 | 일정 화면에서 "2일차 오후를 실내 위주로" 처럼 말하면 전체 일정을 고쳐 줌 + **되돌리기** |
| 장소 편집 | 이름/시간/날짜 이동/분류/비용/메모 수정, 편집 모드에서 ▲▼ 순서 변경 |
| 실제 위치 검색 | OpenStreetMap(Nominatim)으로 장소를 찾아 정확한 좌표 지정 |
| 지도·검색 바로가기 | 국내는 네이버 지도/검색, 해외는 구글 지도/검색으로 연결 |
| 자동 저장 | 저장된 일정은 수정 즉시 저장. AI 생성 일정은 바로 내 일정에 저장 |
| 내 일정 | 다가오는 여행 순 정렬, D-day 표시 |
| 링크 공유 | 일정 전체를 압축해 URL에 담음 (서버 불필요). 받은 사람은 링크를 열고 '저장' |
| 캘린더 | 실제 출발일·시간 기준 .ics 파일 |
| 준비물 체크리스트 | 기본 항목 + AI가 제안한 여행별 팁, 체크 상태 저장 |
| 백업/복원 | 설정에서 JSON 백업 파일 다운로드/불러오기 |
| 큰글씨 모드, 다크 모드 | 기존 기능 유지 |

## 화면 구성 (아이패드·아이폰 우선)

| 기기 | 구성 |
|---|---|
| 아이패드 가로 (폭 1000px 이상) | 왼쪽 사이드바(메뉴 + 다가오는 여행) · 일정 목록 \| 지도 |
| 아이패드 세로 · mini · Split View | 하단 탭바 · 위 지도 / 아래 일정 |
| 아이폰 세로 | 하단 탭바 · 위 지도 / 아래 일정 |
| 아이폰 가로 | 하단 탭바 · 일정 \| 지도 |

- 여행 기간 중이면 오늘 날짜가 자동으로 열리고, 맨 위에 **지금/다음 일정 + 길찾기** 카드가 나옵니다.
- 일정 카드를 누르면 지도가 그 장소로 이동하고, 지도 마커를 누르면 해당 카드로 스크롤됩니다.
- 공유·캘린더·준비물·인쇄·순서 편집은 일정 화면 오른쪽 위 ⋯ 메뉴에 있습니다.

## 지도

| 일정 | 지도 | 실패 시 |
|---|---|---|
| 국내 | 네이버 지도 (Client ID 기본 내장) | 카카오맵(키 있으면) → OpenFreeMap → 기본 지도 |
| 해외 | OpenFreeMap (무료, 키 없음, 지명 한국어 우선) | 기본 지도 |

- 네이버 Client ID는 설정 → 지도에서 바꿀 수 있습니다. 네이버 클라우드 콘솔의 **Maps** 상품에서 Application을 등록하고 Web 서비스 URL에 앱 주소를 넣어야 합니다.
- 다크 모드에서는 OpenFreeMap도 어두운 지도로 바뀝니다.
- 국내 장소의 '지도'·'길찾기' 버튼은 카카오맵을 좌표 기준으로 엽니다(키 불필요). 해외는 구글 지도.
- 위치 확인·장소 검색은 OpenStreetMap을 씁니다.

## 일정 다루기

- **초안 → 저장**: AI가 만든 일정은 먼저 초안으로 보여 줍니다. 마음에 들면 '내 일정에 저장', 아니면 '다시 만들기'. 초안은 새로고침해도 남아 있어요.
- **AI 수정 범위**: 입력창 왼쪽 버튼으로 'Day N만' / '전체'를 고릅니다. 바뀐 장소에는 'AI 변경' 표시가 붙어요.
- **되돌리기**: 장소·날짜·일정 삭제, 장소 편집, 일정 밀기는 알림의 '되돌리기'로 취소할 수 있어요.
- **날짜 추가/삭제**: Day 탭 끝의 '+ 하루 추가', ⋯ 메뉴의 '이 날 삭제'.
- **늦어짐**: 여행 중 '지금/다음 일정' 카드의 '늦어짐'으로 이후 일정을 한 번에 미룹니다. 장소 편집에서 시간을 바꿀 때도 '이후 일정도 같이 밀기'를 고를 수 있어요.
- **이동 수단**: 플래너에서 알아서 / 대중교통 / 자가용·렌터카 / 택시 / 도보 위주를 고르면 AI가 그 기준으로 동선을 짜고, 장소 사이에 '지하철 20분 · 다니마치선 → 난바' 같은 이동 방법을 보여 줍니다. 일정 화면 위쪽에서 바꾸면 AI가 다시 짜 줍니다. 해외 길찾기는 구글 지도에 이동 수단이 반영되고, 국내는 카카오맵에서 고릅니다.
- **식당 후보**: AI는 식사를 '먹자골목' 같은 지역이 아니라 실제 식당으로 정하고, 같은 동네의 다른 식당 2곳을 후보로 함께 줍니다. 식당 카드의 '다른 후보'에서 '이걸로'를 누르면 바뀌고(되돌리기 가능), 후보가 없는 식당은 '후보 추천받기'로 근처 인기 식당 5곳을 받을 수 있습니다.
- **예산**: 여행 스타일에서 소비 성향(가성비/적당히/고급)을 고르고, 필요하면 '예산 직접 정하기'에서 식비·교통비·숙박비를 만 원 단위로 넣습니다(일행 전체·여행 전체 기간). 넣은 항목은 그 금액에 맞추고, 비운 항목은 소비 성향을 따릅니다.
- **예상 비용 카드**: 일정 화면에서 식비·교통비(장소 사이 이동 요금 포함)·숙박비·기타(입장료·쇼핑)를 예산과 비교해 보여 주고, 넘은 항목은 빨간색으로 표시합니다. 택시·자가용·숙소는 일행 전체 금액, 식사·입장료·대중교통은 1인 금액×인원으로 계산합니다.
- **위치 확인**: AI 일정의 장소 좌표를 OpenStreetMap으로 확인해, 크게 어긋난 곳은 자동 보정합니다('위치 보정' 표시).
- **주소 연동**: 화면마다 주소가 있어(#/trip/…) 뒤로 가기·새로고침해도 보던 화면이 유지됩니다. 여행 중이면 앱을 열자마자 그 일정이 나와요.

## 파일 구조

- `index.html` — 화면 구조
- `app.js` — 앱 로직 (화면 전환, 일정 편집, 지도, 저장, 공유, 캘린더)
- `ai.js` — Gemini 호출·프롬프트·응답 정규화, 장소 검색, 공유 링크 인코딩
- `templates.js` — 추천 템플릿 일정과 키 없을 때 쓰는 샘플 생성기
- `styles.css` — 기본 스타일
- `layout.css` — 기기별 레이아웃(아이폰/아이패드), 글자 크기 체계, 터치 영역
- `icons.js` — 선 아이콘 세트
- `ui.js` — 앱 내 확인·입력 대화상자
- `manifest.json`, `sw.js`, `icon*` — PWA(홈 화면 설치, 오프라인)

## 참고

- 비용은 AI가 추정한 **1인 기준 대략치**입니다.
- AI가 준 좌표가 틀릴 수 있습니다. 위치가 이상하면 장소 편집 → 🔍 위치로 다시 지정하세요.
- 모델은 설정에서 바꿀 수 있습니다 (기본 `gemini-3.8-flash`, 저렴하게는 `gemini-3.5-flash-lite`).
